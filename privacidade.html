Política de Privacidade

Última atualização: 2 de novembro de 2026 · Read in English

O PenWeb é uma extensão local-first. O desenvolvedor não mantém um servidor que receba o seu conteúdo e não usa seus dados para publicidade, perfilamento ou venda. Alguns recursos de IA enviam conteúdo à API do provedor que você escolher, somente quando você aciona uma ação e com a sua própria chave.

1. Resumo

  • Fica no seu navegador: grifos, notas, desenhos, mapas, flashcards, histórico de chat, resumos de contexto, anexos recentes, preferências e chaves de API.
  • Sai apenas quando você usa IA: o conteúdo necessário para a tarefa (texto, grifos, página, mensagens anteriores e imagens anexadas) vai direto do navegador para o provedor escolhido.
  • Não fazemos: conta PenWeb, analytics, anúncios, venda de dados ou upload em segundo plano.

2. Definições

Para esta política:

  • PenWeb / Extensão: o aplicativo para Chrome distribuído pela Chrome Web Store e o site oficial.
  • DWLabs / Desenvolvedor: responsável pelo PenWeb, no Brasil.
  • Usuário / você: pessoa que instala ou utiliza o PenWeb.
  • Dispositivo: computador e navegador em que a extensão está instalada.
  • Dados Pessoais: informação que identifica ou pode identificar uma pessoa, que pode estar contida em páginas, grifos, notas ou imagens.
  • Provedor de IA: serviço escolhido por você para processar pedidos de IA, como OpenRouter, Google Gemini, Groq ou DeepSeek; o Ollama roda localmente.
  • Dados de Uso: informações técnicas geradas automaticamente por serviços de terceiros, como logs de acesso do GitHub Pages.
  • Serviço de Terceiro: serviço externo usado para hospedagem, contato, pagamento ou IA.

3. Dados que ficam no seu navegador

O PenWeb usa chrome.storage.local e o armazenamento local do navegador para guardar, no seu dispositivo:

  • marcações e grifos: texto, título e URL da página, cor, nota e explicações geradas por IA;
  • desenhos, autosaves e sessões salvas;
  • mapas mentais, flashcards e preferências de tema, idioma e zoom;
  • histórico de chat por página, resumo de contexto e anexos recentes; imagens mais antigas podem ser removidas automaticamente para economizar espaço;
  • provedor, modelo e chave de API escolhidos.

Esses dados não são sincronizados com servidores do PenWeb. Se você limpar os dados da extensão, apagar conversas/anotações ou desinstalar o PenWeb, eles serão removidos do navegador.

4. Como usamos os dados

  • Dados locais: são usados apenas para oferecer os recursos que você aciona no navegador — desenhar, grifar, anotar, pesquisar, revisar e conversar com a IA.
  • Conteúdo enviado à IA: é usado para produzir a resposta solicitada ao provedor escolhido. Não usamos esse conteúdo para publicidade ou perfilamento.
  • Formulário do site: o e-mail e a finalidade informados são usados para responder ao pedido e enviar novidades do PenWeb.
  • Doações: links de Pix e Mercado Pago abrem serviços externos; o PenWeb não recebe dados de cartão.

5. Recursos de IA e provedores

Os recursos de IA são opcionais. Eles só funcionam quando você configura uma chave de API de um provedor compatível — atualmente OpenRouter, Google Gemini, Groq ou DeepSeek. O Ollama, quando configurado, roda localmente no seu computador. A chave fica no armazenamento local e é enviada apenas ao provedor escolhido, no cabeçalho de autenticação da chamada.

Quando você aciona uma ação de IA (chat, resumo, mapa mental, flashcards, explicação de grifo ou análise de imagem), o PenWeb envia diretamente do seu navegador para a API do provedor o conteúdo necessário para atender ao pedido, que pode incluir:

  • sua pergunta e as instruções do sistema;
  • texto selecionado, grifos e notas;
  • título, URL e texto da página ativa;
  • mensagens anteriores do chat e o resumo de contexto;
  • imagens, prints ou recortes que você anexar ao pedido;
  • identificação do modelo e metadados técnicos da chamada.

O PenWeb não participa desse caminho com servidores próprios e não recebe uma cópia do conteúdo enviado. O provedor escolhido trata os dados conforme a política de privacidade e os termos dele, que podem incluir retenção para segurança e uso para treinamento, dependendo do modelo e do plano (inclusive planos gratuitos). Não controlamos essas práticas. Use os recursos de IA apenas com conteúdo que você tem o direito de compartilhar e evite enviar dados sensíveis.

6. Imagens, prints e capturas de tela

Recortes de região, prints colados e imagens enviadas pelo seletor de arquivos são processados localmente no navegador. Uma imagem só é enviada a um provedor de IA se você a anexar a uma mensagem e enviar o pedido. A captura de região e a exportação em PNG não são enviadas a servidores do PenWeb; a exportação gera um arquivo local para download.

7. Permissões utilizadas

  • activeTab / scripting: para executar a caneta, o marca-texto e os recursos de página somente quando você ativa o PenWeb.
  • Acesso a todos os sites (<all_urls>): necessário para o launcher flutuante e para desenhar, grifar e anotar em qualquer página. Não usamos essa permissão para montar um histórico de navegação nem para ler páginas em segundo plano. A URL ativa é usada localmente para associar anotações e conversas; quando você usa IA, ela pode ser enviada ao provedor junto com o conteúdo do pedido.
  • storage: para guardar anotações, mapas, flashcards, histórico e preferências no navegador.
  • sidePanel: para exibir o painel lateral com chat, grifos e editor de mapas.
  • contextMenus: para adicionar ações do PenWeb ao menu do botão direito.
  • downloads: para salvar imagens e mapas exportados no seu computador.
  • Acesso às APIs dos provedores: para enviar as chamadas de IA que você solicitar.

8. Compartilhamento e o que não fazemos

Compartilhamos conteúdo apenas com o provedor de IA que você escolher, quando você acionar um recurso de IA, e com os serviços necessários para o site (GitHub Pages e FormSubmit, para hospedagem e contato) ou para uma doação que você iniciar (Mercado Pago). Podemos divulgar dados do formulário se formos legalmente obrigados ou para proteger direitos e segurança. Não vendemos, alugamos nem trocamos dados; não usamos analytics, pixels de rastreamento, anúncios ou perfis publicitários; não executamos código remoto.

O uso de dados obtidos por APIs do Chrome segue a Chrome Web Store User Data Policy, incluindo os requisitos de uso limitado (Limited Use).

9. Cookies e tecnologias semelhantes

A extensão não usa cookies de rastreamento nem publicidade. O site é estático, não tem anúncios e não usa analytics. O GitHub Pages pode registrar dados técnicos de acesso conforme a política dele. O formulário de contato usa o FormSubmit para entregar a mensagem; esse serviço pode usar cookies ou tecnologias necessárias ao funcionamento e à proteção contra spam, conforme a política dele. Provedores de IA e de pagamento também podem usar suas próprias tecnologias quando você acessa esses serviços.

10. Base legal, direitos e controle (LGPD)

O tratamento local ocorre no seu dispositivo e sob seu controle. O envio à IA acontece por sua iniciativa ao usar um recurso de IA; o formulário do site é usado para responder ao seu pedido e enviar atualizações que você solicitou. Quando aplicável, tratamos dados com base no consentimento, na execução do serviço solicitado, no cumprimento de obrigações legais ou no legítimo interesse de responder e manter o serviço seguro.

Nos termos da LGPD (Lei 13.709/2018), você pode solicitar confirmação de tratamento, acesso, correção, eliminação, portabilidade, informação sobre compartilhamento e revogação de consentimento. Como os dados locais ficam no seu navegador, você os controla diretamente pelas opções do painel ou limpando os dados da extensão. Para dados do formulário, escreva para o contato abaixo; para dados enviados a um provedor de IA, use os controles e o canal de privacidade desse provedor. Se você estiver no EEE ou no Reino Unido, também pode ter direitos equivalentes previstos na legislação local.

11. Retenção

Os dados locais permanecem no seu navegador até você apagá-los. Dados do formulário são mantidos pelo tempo necessário para responder ao pedido e enviar as atualizações solicitadas, ou até você pedir a remoção. O provedor de IA define o prazo de retenção dele; o GitHub Pages, o FormSubmit e o Mercado Pago mantêm logs e dados conforme as políticas próprias. Não mantemos uma cópia remota dos seus dados locais para restauração.

12. Transferência internacional

Provedores de IA, GitHub Pages, FormSubmit e serviços de pagamento podem processar dados fora do Brasil. Ao usar um recurso de IA, enviar o formulário ou iniciar uma doação, você direciona os dados ao serviço escolhido, que adota as salvaguardas descritas na própria política. Quando exigido, o PenWeb utiliza mecanismos contratuais ou bases legais aplicáveis para o tratamento que estiver sob seu controle.

13. Segurança

As chaves e os dados locais ficam no armazenamento da extensão no seu perfil do Chrome. Adotamos medidas razoáveis para evitar acessos indevidos, mas nenhum sistema é totalmente imune a falhas. Proteja o acesso ao seu computador e à sua conta do navegador; se você usa uma chave de API, revogue-a no provedor se suspeitar de exposição.

14. Crianças e adolescentes

O PenWeb não é direcionado a crianças e não exige conta. Não coletamos intencionalmente dados de crianças pelo site. Se um responsável acredita que uma criança enviou dados pelo formulário, entre em contato para que possamos remover as informações. O uso de recursos de IA por menores deve seguir as regras e a idade mínima do provedor escolhido.

15. Links para sites de terceiros

A extensão e o site contêm links para provedores de IA, serviços de doação, GitHub e outras páginas externas. Não controlamos esses sites e não somos responsáveis pelas práticas de privacidade deles. Leia as políticas dos serviços antes de enviar dados ou concluir uma doação.

16. Alterações nesta política

Podemos atualizar esta política quando o PenWeb ganhar novos recursos ou provedores. A data no topo indica a versão vigente. Mudanças materiais serão destacadas nesta página; o uso contínuo da extensão após a atualização significa que você tomou conhecimento da versão revisada.
